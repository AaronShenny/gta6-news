# GTA 6 Console Performance Debate: Will Players Sacrifice Graphics for 60fps?

This concern leads to a hypothetical scenario: if developers were to implement a 60fps option, it might necessitate a significant downgrade in graphical quality, colloquially referred to as 'potato graphics'. This discussion reflects a common dilemma in console gaming, where developers often balance performance targets with visual ambitions, especially for graphically intensive titles like Grand Theft Auto.

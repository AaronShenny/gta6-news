# GTA 6 'Physical' Copies Vulnerable to Flashlight Code Theft in PEGI Regions

Rockstar Games' highly anticipated Grand Theft Auto 6 is opting for a digital code-in-box approach for its 'physical' release, eschewing traditional discs. However, a significant vulnerability has emerged, primarily affecting copies sold in PEGI regions.

According to reports on forums like ResetEra, the game's download code is printed directly on the inside of the cover. This design choice, combined with the transparency of the game case, allows individuals to shine a flashlight on the cover from the outside and read the code in reverse. This means a potential thief could redeem the code in-store, leaving the legitimate buyer with an unusable, already-redeemed game.

Crucially, this flashlight trick does not seem to work on North American copies of GTA 6, where the codes are reportedly obscured. The reason for this regional discrepancy in packaging security is currently unclear. Gamespot has reached out to Rockstar for an explanation and is awaiting a response.

While the threat of code theft is serious, purchasers can take some solace in knowing that stolen codes cannot be used immediately. Both code-in-box copies and digital pre-orders for PS5 and Xbox Series X|S will only unlock on November 19.
